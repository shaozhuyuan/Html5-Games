How To Play

Control the Code Snake to resolve bugs and grow your software codebase!

  • Use Arrow keys or WASD to move the snake.
  • Eat red blinking Bugs to resolve them.
  • Each bug resolved adds a technology module (e.g. rust, docker, npm) to your body.
  • Do not run into the walls or your own tail (infinite loops) otherwise your project crashes!

INFINITE LOOP! 👾

The program entered a stack overflow / infinite loop crash.

About Code Snake

Code Snake is a web-based coding game inspired by the classic retro snake arcade. Control your snake to catch bugs and build code modules (like rust, docker, and git) without hitting boundaries or tail loops.

Play free in your desktop or mobile browser with keyboard inputs or an on-screen D-Pad. Improve your programming logic, scale your snake length, and see how clean you can compile your virtual codebase!
