## 🛠️ 如何在本地运行
因为每款游戏的所有代码（包含逻辑、样式与图标）都完全自包含在单个 `index.html` 文件中（通过在线 CDN 加载 Tailwind CSS 和图标字体），你不需要任何复杂的构建流程，在本地即可直接运行：

1. 克隆本仓库：
   ```bash
   git clone https://github.com/YOUR_GITHUB_USERNAME/Html5-Games.git
   ```
2. 进入任一游戏文件夹（例如 `/2048`），双击 `index.html` 文件即可在你的浏览器中直接运行游戏。
