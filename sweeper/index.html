How to Play

  • Open cells by left-clicking (or tapping on mobile).
  • The number on an open cell shows how many Syntax Bugs are in its adjacent cells.
  • If you suspect a cell contains a bug, right-click (or long press on mobile) to mark it with a Hotfix Shield.
  • Open all clean cells without triggering a Bug to successfully deploy the build!

About Code Sweeper

Code Sweeper reimagines the retro Minesweeper grid with a software engineering twist. Instead of mines, navigate around syntax exceptions and compiler errors to clean your repository.

Choose between Easy (8x8), Medium (10x10), or Hard (12x12) grids. Track your development deploy time, safely flag bugs, and avoid a system-wide production crash.

Code Sweeper Rules

To compile the system cleanly:

  • Empty Grid Cells: Contain no compile issues.
  • Numbered Cells: 1 to 8 represent the number of adjacent bugs.
  • Bug (Red Spider): Clicking a bug triggers a production stack crash and ends the game.
  • Hotfix (Green Shield): Locks a cell to prevent accidental clicks.
