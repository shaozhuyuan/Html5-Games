How to Play

  • Click on card to flip and reveal its technical icon.
  • Flip another card. If they match, they are cleared via Garbage Collection (GC), reducing RAM usage by -10%.
  • If they do not match, they flip back and increase RAM leak by +5%.
  • RAM usage also leaks automatically over time. Clear all pairs before RAM usage hits 100% (Out Of Memory)!

About Memory Leak

Memory Leak is an intense card-matching puzzle designed with system memory management concepts. Instead of a simple timer, manage your browser's virtual memory footprint.

Match tech stacks (like 🐳 Docker, 🦀 Rust, 💾 Database, 🐛 Bug) while battling progressive leaks. Select Slow, Normal, or Fast leaks. Test your memory speed and see if you can achieve 0% garbage collected RAM.

Memory Leak Rules

Prevent system memory overflow:

  • RAM Leak: RAM increases automatically by a small percentage every second.
  • Matching Cards: Reclaims space via Garbage Collection, reducing RAM by -10%.
  • Mismatch Cards: Adds +5% RAM and temporarily freezes the cards.
  • OOM Crash: Hits 100% RAM before resolving all pairs, resulting in a heap crash.
